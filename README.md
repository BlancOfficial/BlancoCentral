This is a Discord Bot written primarly in JS. It was a Node JS project that I had hosted on a raspberry pi connected to my home network, while it was simple in design it was an amazing introduction to async functions, APIs and Javascript as a whole. It was with writting this project that I also started writing this project and it has undergone a lot of revisions. (This project is currently a private repo on Git)

# BlancoCentral

_To run this discord bot backend, ensure [node.js](https://nodejs.org/en/download/releases/) is downloaded_

---

## Runtime

Remember to add your bot credentials to `auth.json`.

Run the `run.bat` file, alternatively open terminal within the `BlancoBot` folder and enter `node deploy-commands.js`, then `node .`
